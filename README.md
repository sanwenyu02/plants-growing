# plants-growing

A project about growing plants.

## Status

This repository is just getting started — more content is coming soon.

## Contents

- [`loading-page/`](loading-page/index.html) — particle loading animation. Black particles drift like wind, gather into a 3D plant every few seconds, hold, then scatter. Open `index.html` in a browser; call `window.plantLoader.setProgress(0..1)` to drive the progress bar.
